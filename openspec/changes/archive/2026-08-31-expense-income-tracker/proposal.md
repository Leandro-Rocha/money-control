## Why

Managing personal finances in an Excel spreadsheet provides a fast and clear visual overview, but lacks data validation, mobile-friendly usability, and a robust persistence layer. Replacing the spreadsheet with a single-process web application provides the same side-by-side columnar experience (Bank Account with Running Balance + Credit Card Expenses + Category Breakdown) without multi-container or microservice complexity.

This change represents **Phase 1: Core Screen Structure & Services**, establishing the foundational layout, database schema, and core services needed to run the application.

## What Changes

- **Single-Process Web App**: Initialize a lightweight full-stack Next.js app with embedded SQLite database (`better-sqlite3` + Drizzle ORM).
- **Spreadsheet-Inspired Layout**:
  - Top bar with monthly navigation (e.g., "Agosto 2026").
  - Primary Bank Account panel with summary metrics (Total Incomes `↑`, Total Expenses `↓`, Net Balance) and a transaction table showing Day, Description, Category, Amount (green/red), and calculated Running Balance starting from initial balance.
  - Credit Card panel with invoice total header and expense line items.
  - Collapsible / expandable controls on cards and sections for readability.
  - Right-side Category Breakdown panel aggregating monthly expenses per category with sub-item details.
- **Core Data Persistence**: Local SQLite database storing accounts, categories, and transactions.

### Future Roadmap (Planned Separate Specs)
1. **Multi-Account & Multi-Card Management**: Dynamic creation, management, and expand/collapse of multiple bank accounts and credit cards.
2. **Installments & Recurring Transactions**: Native handling of installment plans (e.g., `1/10`) across multiple billing cycles.
3. **LLM Statement Import (PDF/OFX to JSON)**: Ingestion pipeline for structured JSON payloads generated by LLMs analyzing PDF/OFX bank and credit card statements.

## Capabilities

### New Capabilities
- `dashboard-layout`: Side-by-side columnar dashboard replicating spreadsheet UX with month navigation, collapsible panels, and running balance calculation.
- `transaction-management`: Record, edit, delete, and list transactions associated with a bank account or credit card.
- `category-management`: Default and custom category definitions with grouping and summary calculation.
